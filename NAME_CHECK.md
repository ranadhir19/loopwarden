# Name check — harnessforge lab

Checked 2026-11-20 via web search and GitHub search.

## Preferred candidate: `harnessforge` — REJECTED (collision)

The exact name is already in prominent use by other people's software:

- `github.com/jcaiagent7143-ui/harnessforge` — an open-source "harness
  generator for AI coding agents", also published on PyPI as `harnessforge`
  (`uvx harnessforge init` / `pip install harnessforge`).
- "HarnessForge: Joint Harness and Policy Evolution for Adaptive Agent
  Systems" — a paper in the Proceedings of EMNLP 2026, code at
  `github.com/mingju-c/HarnessForge`.
- `github.com/jalajagrawalgenai/HarnessForge` — an MIT-licensed Rust SDK for
  agent harnesses.
- `github.com/ABColliver/HarnessForge-Public` — a wire-harness design tool
  with a live site at harnessforge.app.

Using the same name would collide with all of these, so it was not used.

## Other candidates checked and rejected

- `loopwright` — the trading name of Softvorx, a software-engineering firm
  whose product is built around AI agent harnesses.
- `agentrig` — published on PyPI ("the reliability layer for LLM agents").
- `agentanvil` — published on PyPI (testing/evaluation framework for agents).
- `veriloop` / `verifyloop` — an AI agent reliability platform (Devpost,
  veriloop.vercel.app) and a PyPI package.
- `agentbridle`, `bridle` — `bridle` is a GitHub CLI tool for agentic
  harnesses (neiii/bridle); too close.

## Chosen name: `loopwarden`

Searches for the exact string `"loopwarden"` (web + GitHub, 2026-11-20)
returned **no GitHub repository, no package on PyPI/npm, and no software
product** using the name. The only hits were an unrelated in-game skill name
("Loopwarden") inside the indie game *Striving for Light* — a different
field entirely, not a software tool, repo, or brand.

`loopwarden` is a coined compound in the same style as the rest of the
portfolio (runreckon, evalcrucible, pairseal, verdictpack): the *warden* is
the harness that guards the agent *loop* — bounding its tools, context,
budgets and claims. Final repo name: **loopwarden**.

The local working folder remains `~/workspace/harnessforge/`; the GitHub
repository should be created as `loopwarden`.
